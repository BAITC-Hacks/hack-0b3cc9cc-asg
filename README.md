## FAQ-бот на 5 вопросов

Чат в терминале, который отвечает на 5 заранее известных вопросов про репетицию
(время, команда, трек, сдача, призы). Ответы хранятся в [faq.txt](faq.txt),
бот ищет ближайший вопрос по совпадению ключевых слов (без RAG и без ML).

### Как запустить

Нужен только Python 3 (без зависимостей).

```bash
python bot.py
```

Введите вопрос — бот подберёт ближайший из `faq.txt` по совпадающим ключевым
словам и напечатает ответ. Если совпадений нет — ответит «не знаю».
Для выхода введите `выход` (или `exit`/`quit`).

### Что получилось

- [faq.txt](faq.txt) — 5 пар вопрос-ответ про репетицию.
- [bot.py](bot.py) — читает `faq.txt`, токенизирует вопросы (убирая стоп-слова),
  для каждого вопроса пользователя считает пересечение ключевых слов с каждым
  вопросом из FAQ и выбирает вопрос с максимальным совпадением. Если совпадений
  нет — печатает «не знаю».
- Работает надёжно на прямых формулировках и перефразировках с теми же
  ключевыми словами; для полностью посторонних вопросов возвращает «не знаю».
